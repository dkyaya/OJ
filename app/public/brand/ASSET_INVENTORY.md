# OJ brand asset inventory

Original source package: `OJ_SVGs_PNGs.zip`; originals are preserved in this folder.

| Asset | Role | App use |
| --- | --- | --- |
| `oj-logo-primary-dark.svg` | Primary light-background lockup | Available for light mode and docs |
| `oj-logo-primary-light.svg` | Primary dark-background lockup | Sidebar and loading identity |
| `oj-logo-mark-{orange,white,black}.svg` | Standalone mark variants | Compact mobile/nav branding |
| `oj-wordmark-{dark,light}.svg` | Wordmark variants | Supplemental brand use |
| `oj-app-icon.svg`, `oj-app-icon-1024.png` | App icon | Future PWA/social icon |
| `oj-favicon.svg`, `oj-favicon-{16,32}.png` | Favicons | Browser favicon |

Mapping is based on file names: `light` assets are intended for dark surfaces; `dark` assets for light surfaces. No logo artwork was redrawn or altered.
