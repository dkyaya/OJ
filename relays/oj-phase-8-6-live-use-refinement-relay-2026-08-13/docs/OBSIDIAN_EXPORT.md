# Obsidian Export

OJ can download one trade idea, one catalyst, or a complete ZIP of Markdown files. The full export contains a README, Dashboard, Trade Ideas, Archived Ideas, Catalysts, Trades, Journal, and Research indexes. Filenames are sanitized and unknown values stay `TBD`. Archived research preserves its original status and candidates; the folder placement records its application lifecycle without rewriting the thesis.

The export is a portable copy, not the application's source of truth. Open the extracted folder as an Obsidian vault, copy it into the private `OJ-Journal` repository, or archive it elsewhere. Exporting does not expose brokerage credentials, submit an order, create a branch, or open a pull request.

Permanently deleting an idea from OJ removes its eligible canonical Supabase records, not copies already downloaded or mirrored elsewhere. Obsidian files, the private journal repository, backups, and other external copies must be removed separately when desired.

Because the browser creates the archive locally, private text is not placed in the public repository or a public build artifact.

Authentication, account activation, ordinary saves, and application startup never depend on Obsidian, the private repository, Codex, GitHub credentials, or filesystem access.

Trade files preserve the Phase 8.6 decision story: planned Candidate values, actual execution, original entry thesis and policy context, Catalyst and research references, Check-Ins, and Exit. Linked Journal files include user-authored outcome and reflection fields. These records remain private user exports and must not be committed to the public application repository.
