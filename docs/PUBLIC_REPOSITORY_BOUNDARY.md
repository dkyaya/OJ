# Public repository boundary

Public: React/Vite source, public branding, empty fixtures, Supabase publishable configuration names, migrations, Edge Function source, tests, architecture/security documentation, and public-safe browser screenshots.

Private: Obsidian vault folders, canonical notes, theses, active/closed records, journal reviews, research, emotional check-ins, attachments, real values, immutable payload contents, formalization branches/PRs, and private browser evidence.

The build privacy gate fails when canonical folders exist, nonempty trade/catalyst fixtures exist, credential material appears in public assets, a canonical marker reaches the bundle, or the service worker references authenticated backend traffic.

Historical note: early public commits contained one conceptual SPY note and exact account values. They are absent from current scope; history erasure requires explicit owner approval because it is a force-push operation.
