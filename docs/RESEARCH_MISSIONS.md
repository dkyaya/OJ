# Research Missions

A Research Mission organizes work around one shared catalyst. Roles—Macro Scout, Market Mapper, Options Mechanic, Risk Officer, and Devil's Advocate—are optional labels, not permissions and not completion gates. Assignments can be unassigned, which keeps solo use complete.

Mission checkpoints cover event verification, consensus, bull and bear cases, security mapping, options review, and the trade decision. Options-liquidity observations are manually researched notes with a verification time; OJ does not query or connect to a brokerage.

The server requires at least one evidence card and a completed Event Verified checkpoint before completion. The final decision is Trade, Watch, or No Trade. No Trade is a valid successful result and does not create a position.

The Catalyst War Room groups Summary, Evidence, Mission, Forecasts, and Debrief. Workspace provides an optional cross-catalyst desk view of active missions and questions.
