# Solo-First Collaboration

Collaboration is an enhancement, not a prerequisite.

- A one-person workspace is fully usable.
- Roles and assignments are optional.
- Evidence and forecasts can be authored by the same person.
- Mission completion does not require multiple authors or every optional checkpoint.
- No Trade is a complete research decision.
- Shared sections use clear empty states instead of urging the user to recruit someone.
- The primary navigation remains the six personal product areas. Workspace stays secondary.

Phases 5–8 intentionally exclude live chat, presence, comments on every object, gamification, missions assigned by an administrator, forecast rankings, an onboarding tour, broker tooling, and automated research agents.
