# PWA

OJ exposes a manifest, approved OJ app icon, Apple touch icon, standalone display configuration, and a lightweight offline shell. On iPhone, open the Pages URL in Safari and choose **Share → Add to Home Screen**. IndexedDB edits save immediately; after owner sign-in and approval, cloud drafts hydrate and synchronize across devices. Unsynced edits remain device-only. Magic links should be opened on the same device/browser that requested them so the PKCE verifier is available.
